# 泾渭分明 · 才思相融

[打开网站](https://84586854.github.io/jingwei-poetry/)

以双河汇流为意象，探索李白与杜甫的全部 23,448 条原始诗句相似配对。包括卷首山水、双河观流、作品矩阵、原句对读、分布与门槛曲线、作品筛选、链接分享和 CSV 导出，适配手机与桌面。

当前仓库中的 index.html 为完整发布版，图片、数据、样式与交互全部内置，不依赖外部服务。原始 Excel 可在网站卷后下载。

[下载可编辑完整源码](./jingwei-source.zip)

源码包包含分离的 HTML/CSS/JavaScript、原始 Excel、无损数据、数据导入器、测试、构建脚本和可选 GitHub Actions 工作流。构建单文件版本：node scripts/build-single.mjs。

发布方式：GitHub Pages → Deploy from a branch → main / (root)。

相似度仅描述收录诗句的文本联系，不是两部文集整体相似率，也不判定引用或影响。山水图为 AI 生成艺术意象；河面最多显示按排名均匀抽取的 72 条，完整配对在拾句中提供。
